Portfolio editor

Everything you can change on the site, in one place. Nothing here breaks the design, only the words.

How this works

  1. Change anything on this page. Your changes stay here while you work.
  2. Click Save locally — it writes content.js (and any picked images/videos) straight into the site folder. No downloading, no replacing.
  3. The site tab refreshes itself — switch to it and watch it update. (If you ever open the site from file:// instead of the server, hit ⌘R instead.)

Save locally needs the little local server running: double-click Start Site.command in the portfolio folder, and open the site (and admin) from the address it shows — http://127.0.0.1:8888/.... It also works if you open admin straight from the folder (file://) — the button just talks to the server on port 8888.

Going live later? Connect GitHub in the section below and hit Save to GitHub — it pushes content.js, admin.html and picked files to your repo, and updates the live site once Pages is on. No downloads either way. Download / Copy / Load stay as backups.

Publish to GitHub (optional)

Saves your content straight to the repository, on the branch your GitHub Pages site serves from, then waits and confirms when the live site is actually updated. It also pushes this admin editor itself, so the live admin.html always matches the version you're using — no downloading files. The token stays in your browser only (this page's storage). Treat it like a password; revoke it anytime at github.com/settings/tokens.

How to get one: github.com/settings/tokens → Generate new token (fine-grained) → Repository access: only select repositories, pick the one that hosts this site → Permissions: Contents → Read and write (required), plus Pages → Read (optional, lets the save button wait and confirm the live update). Generate token. Paste it here.

2. The ticket (home page)

The whole home page is one lottery ticket, and every line of it is here. Nothing is hidden behind a scratch panel any more, so whatever you write gets read.

The stamp

The postage stamp on the right of the ticket. It is the only picture on the home page, and clicking it opens whichever page you point it at. Empty both the words and the photo and the whole stamp disappears.

When you finally win something

Leave the box below empty and the site runs the "award-losing" version. Type an award into it (one per line) and the home page flips itself to the correction-notice version and prints what you won. That is the whole switch, nothing else to change.

3. The quiet jokes

Small places a joke can hide, where finding one feels like a reward instead of a demand. Empty any of them and that slot just goes silent. These are Claude's drafts, so rewrite them in your voice or delete them.
