Drowner is not in this folder, so it cannot be shown

The last version of this page faked it. It fell back to Syne and labelled that panel "Drowner", which is why the two looked identical. It will not do that again: the switch above stays dead until the real file is here.

  1. Open Hainz Studio's own Behance page and take the free download. The link on that page goes to the designer's own file, which is the version to use.
  2. Unzip it. Put one file in the fonts folder next to this page and name it Drowner.otf, Drowner.ttf or Drowner.woff2.
  3. Refresh. The switch turns on.

It cannot leak. fonts/ is in .gitignore, so the file stays on your machine and git will not take it even if you try. That matters: "free for commercial use" lets you set type with a font, not hand the file to everyone who visits the site. Nothing goes live until you have the licence sorted and we build it in deliberately.
